# RefBoard

**영상 레퍼런스 보드**입니다. NAS(WebDAV)나 로컬·SMB 폴더의 영상을 탐색해서 보드에 띄우고, 구간 반복·프레임 단위 이동·그리기로 동작을 분석합니다. **Blender 애드온**과 연결하면 Blender 타임라인에 맞춰 영상이 움직입니다.

![RefBoard 보드](docs/screenshots/board.png)

## 주요 기능

- **무한 보드**: 영상·GIF·이미지를 끌어다 놓고 자유롭게 배치합니다. 보드는 자동 저장되고, `.refboard` 파일로 따로 저장할 수도 있습니다.
- **NAS 탐색**: WebDAV(Synology 등)와 로컬·SMB 폴더. 수천 개 영상도 썸네일 캐시로 빠르게 넘겨 봅니다.
- **반복 구간 여러 개**: 이름을 붙여 파일마다 저장하고, 구간 썸네일로 바로 갑니다.
- **구간 라이브러리**: 쌓인 구간을 폴더 / 태그로 정리하고 검색으로 찾습니다.
- **프레임 단위 분석**: 실제 fps로 한 프레임씩 이동하고, 속도를 바꾸고, 좌우·상하 반전·흑백·자르기를 합니다.
- **그리기**: 펜·화살표·원으로 영상 위에 표시합니다. 그림은 보드 파일에 함께 저장됩니다.
- **항상 위 · 투명도**: 다른 프로그램(예: Blender) 위에 띄워 두고 봅니다.
- **언어**: 한국어, English, 日本語. 처음에는 Windows 언어를 따르고, **⚙ 설정 ▸ 🌐**에서 언제든 바꿉니다.
- **Blender 연결**: 타임라인 동기화, 구간 반복, Space 재생, 뷰포트와 카메라 배경에 영상 띄우기.

## 다운로드 · 설치

[Releases](../../releases)에서 받습니다.

| 파일 | 내용 |
| --- | --- |
| `RefBoard-Setup-x.y.z.exe` | Windows 설치 프로그램 (Windows 10/11, 64비트) |
| `RefBoard-Blender-Addon-x.y.z.zip` | Blender 애드온 (Blender 4.2 이상). 설치 프로그램에도 들어 있어서 따로 받지 않아도 됩니다 |

- 설치 프로그램은 코드 서명이 되어 있지 않아서, 처음 실행할 때 Windows SmartScreen 경고가 나올 수 있습니다. **추가 정보 ▸ 실행**을 누르세요.
- **FFmpeg가 필요합니다** (썸네일과 fps 읽기). PATH에 있으면 그대로 쓰고, 아니면 설정에서 `ffmpeg.exe` 경로를 지정합니다.

  ```bash
  winget install Gyan.FFmpeg
  ```

## 처음 설정: NAS 연결

처음 실행하면 **⚙ 설정**이 열립니다. 여기서 소스를 추가하세요.

<img src="docs/screenshots/nas-settings.png" width="420" alt="NAS 연결 설정">

| 종류 | 주소 예시 |
| --- | --- |
| WebDAV | `https://192.168.0.10:5006/refs` (Synology: WebDAV Server 패키지, HTTPS 5006 / HTTP 5005) |
| 로컬 · SMB 폴더 | `\\NAS\refs`, `Z:\refs` |

- 비밀번호는 Windows 보안 저장소(DPAPI)로 암호화해서 `%APPDATA%\refboard\config.json`에 저장합니다.
- Synology 기본 인증서처럼 자체 서명 인증서를 쓰면 **자체 서명 인증서 허용**을 체크하세요.
- 디스크 절전 중인 NAS는 첫 응답에 10~30초 걸릴 수 있습니다. 그동안 패널에 기다리는 중이라고 나옵니다.

## 사용법

### 보드

- 왼쪽 패널에서 영상을 **끌어다 놓거나 더블클릭**하면 보드에 열립니다. 탐색기에서 파일을 바로 끌어와도 됩니다.
- 영상 위에 마우스를 올리면 컨트롤이 나옵니다. ✕ 또는 `Delete`로 닫습니다.
- 보드는 자동 저장되고 다음 실행 때 복원됩니다. `Ctrl+S`를 누르면 `.refboard` 파일로 저장합니다.
- **보드에 올린 영상 표시:** 패널 카드에 파란 체크가 붙습니다. 같은 영상을 2개 이상 올리면 개수도 함께 표시됩니다.
  - 카드를 우클릭하면 **보드에서 보기**(보드의 그 영상으로 이동), 하나 더 올리기, 모두 닫기, 경로 복사를 할 수 있습니다.
- **재생 바:** 레퍼런스 바로 아래에 붙습니다. 마우스를 올리거나 선택하면 나타나고, 확대/축소와 상관없이 같은 크기로 보입니다.
- **보드 영상 우클릭:** 구간 만들기와 조절, 구간 고르기, 재생, 소리, 반전/흑백/자르기, 패널에서 위치 보기, 닫기가 있습니다.
- 레퍼런스 영상은 항상 음소거로 시작합니다.
- 단축키는 `F1`을 누르면 나옵니다. Space 재생, ←/→ 프레임 이동, `[` `]` 반복 구간, `1`~`9`/`0` 구간 고르기, `-` `=` 속도, `Ctrl+T` 항상 위, Tab 패널 열기/닫기.

### 반복 구간

![반복 구간](docs/screenshots/ranges.png)

- **만들기**
  - `[`로 시작을, `]`로 끝을 정하면 구간이 생깁니다. 재생 바의 구간 버튼을 시작과 끝에서 한 번씩 눌러도 됩니다.
  - 우클릭(진행 바 위면 그 지점, 영상 위면 현재 위치)으로도 만들 수 있습니다.
  - 경계는 프레임에 맞춰지고, `]`를 누를 때 보이던 프레임까지 구간에 들어갑니다.
- **고르기 · 고치기 · 지우기**
  - 진행 바 아래의 구간 칩을 누르거나 `1`~`9`를 누르면 그 구간만 반복합니다. **전체** 칩이나 `0`(또는 `\`)은 전체 재생입니다.
  - 구간을 반복하는 중에 `[` `]`를 누르거나 진행 바의 색 손잡이를 끌면 그 구간의 시작/끝이 바뀝니다.
  - 칩에 마우스를 올리면 나오는 ×, 또는 칩 우클릭 메뉴로 지웁니다.
- **이름 붙이기:** 칩을 더블클릭하거나, `F2`(반복 중인 구간)나 우클릭 ▸ 이름 붙이기… 를 씁니다. `Enter`로 저장, `Esc`로 취소합니다.
- 구간을 반복하는 동안 프레임 번호는 그 구간 안에서 셉니다(예: 5 / 25).
- **구간 썸네일**
  - 보드: 구간이 있는 레퍼런스 옆에 구간마다 첫 프레임 썸네일이 세로로 붙습니다. 누르면 그 구간을 반복하고, 다시 누르면 전체를 재생합니다.
  - 패널: 구간이 저장된 파일 카드에 ⟳ 숫자 표시가 붙습니다. 누르면 카드 아래에 구간 썸네일이 펼쳐지고, 누르면 보드에서 그 구간으로 갑니다.
- **구간은 파일마다 저장됩니다.** 같은 영상을 다른 보드에서, 나중에 다시 열어도 그대로 나옵니다.

### 구간 라이브러리

- 왼쪽 패널 위의 **구간** 탭. 보드에서 만든 구간이 모두 자동으로 모입니다(처음엔 **미분류**).
- **폴더:** **＋**로 폴더를 만들고, 폴더를 우클릭해 하위 폴더 만들기 / 이름 바꾸기 / 삭제를 합니다. 폴더를 지워도 안의 구간은 지워지지 않고 미분류로 옮겨집니다.
  - 구간 카드를 폴더 위로 끌어다 놓거나, 카드 우클릭 ▸ **폴더로 옮기기**로 넣습니다. 상위 폴더를 고르면 하위 폴더의 구간도 함께 보입니다.
- **태그:** 카드 우클릭 ▸ **태그…** 에서 쉼표나 띄어쓰기로 여러 개 답니다. 이미 쓰는 태그는 눌러서 넣을 수 있습니다.
- **찾기:** 검색창은 구간 이름, 파일 이름, 태그, 폴더 이름에서 찾습니다. `#태그`를 쓰거나 위쪽 태그 칩을 누르면 그 태그만 남깁니다(여러 개 = 모두 가진 것).
- 카드를 누르면 보드에서 그 구간을 반복합니다. 보드에 없던 영상이면 올리고 그 구간부터 재생합니다.
- 보드의 구간 칩 우클릭 메뉴에서도 **태그… / 폴더로 옮기기…** 를 쓸 수 있고, 어느 쪽에서 고쳐도 양쪽에 바로 반영됩니다.

### 프레임 · 반전 · 자르기

- **프레임 단위 이동:** 영상마다 실제 프레임 레이트(24 / 29.97 / 60 fps 등)를 ffprobe로 읽습니다.
  - `←` `→`는 정확히 한 프레임, `Shift`와 함께 누르면 1초 분량을 이동합니다.
  - 재생 바에 프레임 번호(예: 36 / 96)가 보이고, 마우스를 올리면 fps가 나옵니다.
- **반전 · 흑백 · 자르기:** 영상, GIF, 이미지 모두 되고 보드에 저장됩니다.
  - `Shift+H` 좌우 반전, `Shift+V` 상하 반전, `Shift+G` 흑백.
  - `C`를 누르면 자르기 영역이 나타납니다. 모서리·가장자리를 끌어 크기를, 안쪽을 끌어 위치를 바꾸고 `Enter`로 적용합니다. 우클릭 ▸ **자르기 해제**로 되돌립니다.
- **GIF:** 영상과 같은 재생 바를 씁니다. 프레임마다 다른 표시 시간도 그대로 지켜 재생합니다.
  - **모든 프레임 보기**(재생 바의 칸 아이콘 또는 `G`)를 켜면 프레임이 격자로 펼쳐지고, 누르면 그 프레임으로 갑니다.

### 그리기

![그리기](docs/screenshots/draw.png)

- 상단 **✎ 그리기** 버튼이나 `D`를 누르면 그리기 모드가 됩니다.
- 도구: 펜(`P`), 화살표(`A`), 원(`O`), 지우개(`E`). 지우개는 선을 문지르면 그 선이 통째로 지워집니다.
- 색은 툴바에서 고르고, 굵기는 슬라이더나 `Alt+휠`로 바꿉니다. `Ctrl+Z` / `Ctrl+Y`로 되돌리고 다시 합니다. `H`는 그림 숨기기/보이기입니다.
- 그림은 영상에 붙어 있어서 영상을 옮기거나 크기를 바꾸면 같이 따라갑니다.

### 네트워크 · 메모리 아끼기

- 멈춘 채로 올린 영상은 NAS에서 아무것도 받지 않습니다. 그 시각의 썸네일을 보여 주고, 재생하거나 이동할 때 비로소 받습니다.
- 보드를 움직여 화면 밖으로 나간 영상은 자동으로 일시정지되고, 돌아오면 다시 재생됩니다.
- 화면 밖에 8초 넘게 있으면 지금 프레임을 정지 화면으로 남기고 영상을 내려 메모리를 돌려줍니다.
- NAS 연결은 하나만 열어 4MB씩 나눠 받습니다. 새 연결마다 로그인이 느린 NAS에서도 여러 영상이 멈추지 않습니다.

재생 가능 형식: H.264 / H.265(HEVC) / VP9 / AV1 (mp4, mov, m4v, webm, mkv). ProRes는 재생하지 못합니다.

## Blender와 연결하기

![Blender 연결](docs/screenshots/blender.png)

데스크톱 RefBoard 창을 그대로 쓰면서 Blender와 연결합니다. RefBoard를 Blender 위에 두려면 **📌 항상 위**와 **투명도**를 쓰세요.

- **설치 (자동):** RefBoard를 처음 실행하면 이 PC의 Blender(4.2 이상)를 찾아 **"Blender 애드온을 설치할까요?"** 하고 묻습니다. **설치**를 누르면 됩니다.
  - 애드온은 RefBoard 안에 들어 있어서 따로 받지 않습니다. Blender의 애드온 폴더(`%APPDATA%\Blender Foundation\Blender\<버전>\scripts\addons`)에 복사합니다.
  - **다음에 Blender를 켤 때 자동으로 켜집니다.** (켜 주는 일회용 시작 스크립트를 함께 넣고, 한 번 실행되면 지워집니다.) Blender가 켜져 있었다면 껐다가 다시 켜세요.
  - RefBoard를 새 버전으로 바꾸면, 설치된 애드온이 더 오래된 경우 자동으로 새 버전으로 바꿉니다.
  - 나중에 하려면 **⚙ 설정 ▸ Blender 애드온 설치 / 업데이트**를 누르세요. 버전별 설치 상태도 거기서 보입니다.
- **설치 (직접):** Blender ▸ Edit ▸ Preferences ▸ Add-ons ▸ ▾ ▸ **Install from Disk…** ▸ `RefBoard-Blender-Addon-x.y.z.zip` 선택 → **RefBoard 연결** 켜기
- **연결은 자동입니다.** RefBoard와 Blender 중 어느 쪽을 먼저 켜도 되고, 한쪽을 다시 켜면 다시 이어집니다.
  - RefBoard 제목 표시줄에 현재 Blender 프레임이, Blender 상단 바 오른쪽 **RefBoard** 버튼에 연결 상태가 보입니다.
- **RefBoard 열기:** Blender 상단 바의 **RefBoard** 버튼, `Ctrl+Alt+R`, 또는 3D 뷰 사이드바(`N`) ▸ **RefBoard** 탭. 꺼져 있으면 켜고, 켜져 있으면 앞으로 가져옵니다.
  - 설치된 RefBoard를 자동으로 찾습니다(RefBoard를 한 번 실행한 뒤부터는 항상).
- RefBoard는 하나만 켜집니다. 연결은 이 PC 안(127.0.0.1)에서만, 일회용 토큰으로 합니다.

**Blender 타임라인에 맞추기**
- Blender와 연결되면 영상·GIF의 재생 바에 🔗 버튼이 생깁니다. 🔗, `L`, 또는 우클릭 ▸ **Blender 타임라인에 맞추기**로 켭니다.
  - 누르는 순간의 "Blender 프레임 = 지금 레퍼런스 프레임"이 기준점이 됩니다.
- Blender에서 스크럽하거나 프레임을 넘기면 레퍼런스가 같은 시점의 프레임으로 이동합니다. **시간 기준**이라 fps가 달라도 같은 순간이 보입니다(예: 29.97fps 영상의 99번째 프레임 = 24fps 씬의 80프레임).
- Blender를 재생하면 레퍼런스도 함께 재생하고, 어긋나면 재생 속도를 살짝 바꿔 따라잡습니다.
- 맞춘 상태에서 레퍼런스를 `←` `→`로 움직이거나 진행 바를 끌면 그 위치로 기준점이 다시 잡힙니다.
- 맞춘 레퍼런스에 반복 구간이 있으면 **Blender 미리보기 범위도 그 구간에 맞춰져**, Blender 재생도 같은 구간을 반복합니다.
  - 구간을 끄거나, 동기화를 끄거나, 연결이 끊기면 원래 미리보기 범위로 돌아갑니다.
  - 구간 시작이 장면 시작 프레임보다 앞으로 계산되면 기준점을 "구간 시작 = 장면 시작 프레임"으로 다시 잡습니다. 음수 프레임으로 가지 않습니다.
- 맞춘 레퍼런스에서 `Space`나 재생 버튼을 누르면 **Blender 재생**이 켜지고 꺼집니다.

**Blender 뷰포트에 띄우기**
- RefBoard에서 영상을 우클릭 ▸ **Blender 뷰포트에 띄우기**. 3D 커서 자리에 정면(Front 뷰 방향)을 보는 레퍼런스 이미지(Empty)로 들어갑니다.
- 일반 오브젝트처럼 옮기고 돌리고 크기를 바꿀 수 있습니다. 사이드바(`N`) ▸ **RefBoard** 탭에서 크기·불투명도를 바꾸거나 지웁니다.
- 어느 영상 프레임을 보일지 매 프레임 RefBoard와 같은 식으로 계산합니다. fps가 달라도, 재생 속도를 바꿔도, 반복 구간이 있어도 RefBoard와 같은 프레임이 보입니다.

**카메라 배경으로 보내기**
- RefBoard에서 영상을 우클릭 ▸ **Blender 카메라 배경으로 보내기**. 활성 카메라의 배경 영상(무비 클립)으로 들어갑니다. 카메라 시점(`Numpad 0`)에서 보입니다.
- NAS 영상은 한 번 받아 `%APPDATA%\refboard\blender-clips`에 둡니다.

## 소스에서 실행 · 빌드

[Node.js](https://nodejs.org/) 20 이상이 필요합니다.

```bash
npm install
```

```bash
npm start
```

- 소스에서 실행하는 동안 코드가 바뀌면 화면 위쪽에 **새 버전 알림**이 뜹니다(설치판에서는 꺼져 있음).
- Blender 애드온 설정의 **소스 폴더(개발용)**에 이 폴더를 지정하면, 애드온의 **RefBoard 열기**가 소스에서 실행합니다.

릴리즈 파일 만들기 (`dist/`에 생깁니다):

```bash
npm run dist
```

```bash
npm run addon
```

자동 점검(테스트용 WebDAV 또는 폴더 필요):

```bash
npm run selftest
```

환경 변수 `RB_TEST_URL` / `RB_TEST_USER` / `RB_TEST_PASS`(WebDAV) 또는 `RB_TEST_TYPE=local`과 `RB_TEST_URL=<폴더>`로 테스트 소스를 정합니다.

로고를 바꾸려면 `assets/logo-source.png`(흰 바탕 검은 로고)를 교체하고 `python scripts/make-icons.py`를 실행합니다.
