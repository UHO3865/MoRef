# RefBoard

**動画リファレンスボード**です。NAS(WebDAV)やローカル・SMB フォルダの動画を探してボードに並べ、区間ループ・コマ送り・描き込みで動きを分析します。**Blender アドオン**と接続すると、Blender のタイムラインに合わせて動画が動きます。

> アプリの画面は現在韓国語のみです。以下のボタン名は日本語訳と韓国語の表示を併記しています。

![RefBoard ボード](docs/screenshots/board.png)

## 主な機能

- **無限ボード**: 動画・GIF・画像をドラッグして自由に配置します。ボードは自動保存され、`.refboard` ファイルとして別に保存することもできます。
- **NAS ブラウズ**: WebDAV(Synology など)とローカル・SMB フォルダ。数千本の動画もサムネイルキャッシュで素早く見られます。
- **複数のループ区間**: 名前を付けてファイルごとに保存し、区間サムネイルからすぐ移動できます。
- **コマ単位の分析**: 実際の fps で 1 コマずつ移動し、速度変更、左右・上下反転、白黒、切り抜きができます。
- **描き込み**: ペン・矢印・円で動画の上に書き込めます。描き込みはボードファイルと一緒に保存されます。
- **常に手前 · 透明度**: ほかのアプリ(例: Blender)の上に浮かべて見られます。
- **Blender 連携**: タイムライン同期、区間ループ、Space で再生、ビューポートやカメラ背景に動画を表示。

## ダウンロード · インストール

[Releases](../../releases) からダウンロードします。

| ファイル | 内容 |
| --- | --- |
| `RefBoard-Setup-x.y.z.exe` | Windows インストーラー (Windows 10/11, 64 ビット) |
| `RefBoard-Blender-Addon-x.y.z.zip` | Blender アドオン (Blender 4.2 以降)。インストーラーにも含まれているので、別途ダウンロードしなくてもかまいません |

- インストーラーはコード署名されていないため、初回実行時に Windows SmartScreen の警告が出ることがあります。**詳細情報 ▸ 実行** を押してください。
- **FFmpeg が必要です**(サムネイルと fps の読み取り)。PATH にあればそのまま使い、なければ設定で `ffmpeg.exe` のパスを指定します。

  ```bash
  winget install Gyan.FFmpeg
  ```

## 初期設定: NAS の接続

初回起動時に **設定 (⚙ 설정)** が開きます。ここでソースを追加してください。

<img src="docs/screenshots/nas-settings.png" width="420" alt="NAS 接続設定">

| 種類 | アドレスの例 |
| --- | --- |
| WebDAV | `https://192.168.0.10:5006/refs` (Synology: WebDAV Server パッケージ, HTTPS 5006 / HTTP 5005) |
| ローカル · SMB フォルダ | `\\NAS\refs`, `Z:\refs` |

- パスワードは Windows のセキュアストア(DPAPI)で暗号化して `%APPDATA%\refboard\config.json` に保存します。
- Synology の既定の証明書のような自己署名証明書を使う場合は、**自己署名証明書を許可 (자체 서명 인증서 허용)** にチェックを入れてください。
- ディスクがスリープ中の NAS は、最初の応答に 10〜30 秒かかることがあります。その間、パネルに待機中と表示されます。

## 使い方

### ボード

- 左のパネルから動画を **ドラッグするかダブルクリック** するとボードに開きます。エクスプローラーからファイルを直接ドラッグしてもかまいません。
- 動画にマウスを乗せるとコントロールが表示されます。✕ または `Delete` で閉じます。
- ボードは自動保存され、次回起動時に復元されます。`Ctrl+S` で `.refboard` ファイルに保存します。
- **ボードに置いた動画の表示:** パネルのカードに青いチェックが付きます。同じ動画を 2 つ以上置くと数も表示されます。
  - カードを右クリックすると **ボードで表示 (보드에서 보기)**(ボード上のその動画へ移動)、もう 1 つ追加、すべて閉じる、パスのコピーができます。
- **再生バー:** リファレンスのすぐ下に付きます。マウスを乗せるか選択すると表示され、拡大・縮小に関係なく同じ大きさで表示されます。
- **ボードの動画を右クリック:** 区間の作成と調整、区間の選択、再生、音声、反転/白黒/切り抜き、パネルで場所を表示、閉じる。
- リファレンス動画は常にミュートで始まります。
- ショートカットは `F1` で表示されます。Space 再生、←/→ コマ送り、`[` `]` ループ区間、`1`〜`9`/`0` 区間の選択、`-` `=` 速度、`Ctrl+T` 常に手前、Tab パネルの表示/非表示。

### ループ区間

![ループ区間](docs/screenshots/ranges.png)

- **作成**
  - `[` で開始、`]` で終了を決めると区間ができます。再生バーの区間ボタンを開始と終了で 1 回ずつ押してもかまいません。
  - 右クリック(進行バーの上ならその位置、動画の上なら現在位置)でも作れます。
  - 境界はコマに合わせられ、`]` を押したときに見えていたコマまで区間に含まれます。
- **選択 · 修正 · 削除**
  - 進行バーの下の区間チップを押すか `1`〜`9` を押すと、その区間だけをループします。**全体 (전체)** チップや `0`(または `\`)で全体再生です。
  - 区間のループ中に `[` `]` を押すか、進行バーの色付きハンドルをドラッグすると、その区間の開始/終了が変わります。
  - チップにマウスを乗せると出る ×、またはチップの右クリックメニューで削除します。
- **名前を付ける:** チップをダブルクリックするか、`F2`(ループ中の区間)または右クリック ▸ 名前を付ける… (이름 붙이기…) を使います。`Enter` で保存、`Esc` で取り消し。
- 区間のループ中、コマ番号はその区間の中で数えます(例: 5 / 25)。
- **区間サムネイル**
  - ボード: 区間のあるリファレンスの横に、区間ごとの最初のコマのサムネイルが縦に並びます。押すとその区間をループし、もう一度押すと全体を再生します。
  - パネル: 区間が保存されたファイルのカードに ⟳ 数字が付きます。押すとカードの下に区間サムネイルが展開され、押すとボード上のその区間へ移動します。
- **区間はファイルごとに保存されます。** 同じ動画を別のボードで、または後で開いても、そのまま表示されます。

### コマ · 反転 · 切り抜き

- **コマ送り:** 動画ごとの実際のフレームレート(24 / 29.97 / 60 fps など)を ffprobe で読み取ります。
  - `←` `→` で正確に 1 コマ、`Shift` と一緒なら 1 秒分移動します。
  - 再生バーにコマ番号(例: 36 / 96)が表示され、マウスを乗せると fps が表示されます。
- **反転 · 白黒 · 切り抜き:** 動画・GIF・画像のすべてで使え、ボードに保存されます。
  - `Shift+H` 左右反転、`Shift+V` 上下反転、`Shift+G` 白黒。
  - `C` を押すと切り抜き範囲が表示されます。角や辺をドラッグして大きさを、内側をドラッグして位置を変え、`Enter` で適用します。右クリック ▸ **切り抜きを解除 (자르기 해제)** で元に戻します。
- **GIF:** 動画と同じ再生バーを使います。コマごとに異なる表示時間もそのまま守って再生します。
  - **すべてのコマを表示 (모든 프레임 보기)**(再生バーのグリッドアイコン または `G`)をオンにするとコマがグリッド状に並び、押すとそのコマへ移動します。

### 描き込み

![描き込み](docs/screenshots/draw.png)

- 上部の **✎ 描く (그리기)** ボタンか `D` で描き込みモードになります。
- ツール: ペン(`P`)、矢印(`A`)、円(`O`)、消しゴム(`E`)。消しゴムは線をなぞるとその線がまるごと消えます。
- 色はツールバーで選び、太さはスライダーか `Alt+ホイール` で変えます。`Ctrl+Z` / `Ctrl+Y` で元に戻す/やり直し。`H` で描き込みの表示/非表示。
- 描き込みは動画に付いているので、動画を移動したり大きさを変えたりすると一緒に付いてきます。

### 通信量・メモリの節約

- 一時停止のまま置いた動画は NAS から何もダウンロードしません。その時点のサムネイルを表示し、再生や移動をしたときに初めてダウンロードします。
- ボードを動かして画面外に出た動画は自動で一時停止し、戻ると再生を再開します。
- 画面外に 8 秒以上あると、現在のコマを静止画として残し、動画を解放してメモリを返します。
- NAS への接続は 1 本だけ開き、4MB ずつ分けて読み込みます。新しい接続ごとのログインが遅い NAS でも、複数の動画が止まりません。

再生できる形式: H.264 / H.265(HEVC) / VP9 / AV1 (mp4, mov, m4v, webm, mkv)。ProRes は再生できません。

## Blender との接続

![Blender 接続](docs/screenshots/blender.png)

デスクトップの RefBoard ウィンドウをそのまま使いながら Blender と接続します。RefBoard を Blender の上に置くには **📌 常に手前 (항상 위)** と **透明度 (투명도)** を使ってください。

- **インストール(自動):** 初回起動時に、この PC の Blender(4.2 以降)を見つけて「Blender アドオンをインストールしますか?」と尋ねます。**インストール (설치)** を押してください。
  - アドオンは RefBoard の中に入っているので、別途ダウンロードは不要です。Blender のアドオンフォルダ(`%APPDATA%\Blender Foundation\Blender\<バージョン>\scripts\addons`)にコピーします。
  - **次に Blender を起動したとき自動で有効になります。**(有効化する使い捨てのスタートアップスクリプトを一緒に入れ、1 回実行されると自身を削除します。)Blender が起動中だった場合は再起動してください。
  - RefBoard を新しいバージョンにすると、インストール済みのアドオンが古い場合は自動で新しいバージョンに置き換えます。
  - 後で行う場合は **⚙ 設定 ▸ Blender アドオンのインストール / 更新 (Blender 애드온 설치 / 업데이트)** を押してください。バージョンごとのインストール状態もそこに表示されます。
- **インストール(手動):** Blender ▸ Edit ▸ Preferences ▸ Add-ons ▸ ▾ ▸ **Install from Disk…** ▸ `RefBoard-Blender-Addon-x.y.z.zip` を選択 → **RefBoard 연결** を有効化
- **接続は自動です。** RefBoard と Blender のどちらを先に起動してもよく、どちらかを再起動すると再接続します。
  - RefBoard のタイトルバーに現在の Blender のフレームが、Blender のトップバー右の **RefBoard** ボタンに接続状態が表示されます。
- **RefBoard を開く:** Blender のトップバーの **RefBoard** ボタン、`Ctrl+Alt+R`、または 3D ビューのサイドバー(`N`) ▸ **RefBoard** タブ。起動していなければ起動し、起動していれば前面に出します。
  - インストールされた RefBoard を自動で見つけます(RefBoard を一度起動した後は常に)。
- RefBoard は 1 つだけ起動します。接続はこの PC 内(127.0.0.1)だけで、使い捨てのトークンで行います。

**Blender のタイムラインに合わせる**
- Blender と接続すると、動画・GIF の再生バーに 🔗 ボタンが現れます。🔗、`L`、または右クリック ▸ **Blender のタイムラインに合わせる (Blender 타임라인에 맞추기)** でオンにします。
  - 押した瞬間の「Blender のフレーム = 現在のリファレンスのコマ」が基準点になります。
- Blender でスクラブしたりフレームを送ったりすると、リファレンスが同じ時点のコマへ移動します。**時間基準**なので、fps が違っても同じ瞬間が表示されます(例: 29.97fps の動画の 99 コマ目 = 24fps のシーンの 80 フレーム目)。
- Blender を再生するとリファレンスも一緒に再生し、ずれたら再生速度を少し変えて追いつきます。
- 合わせた状態でリファレンスを `←` `→` で動かすか進行バーをドラッグすると、その位置で基準点を取り直します。
- 合わせたリファレンスにループ区間があると、**Blender のプレビュー範囲もその区間に合わせられ**、Blender の再生も同じ区間をループします。
  - 区間をオフにする、同期をオフにする、または接続が切れると、元のプレビュー範囲に戻ります。
  - 区間の開始がシーンの開始フレームより前に計算される場合は、基準点を「区間の開始 = シーンの開始フレーム」に取り直します。負のフレームにはなりません。
- 合わせたリファレンスで `Space` や再生ボタンを押すと、**Blender の再生** をオン/オフします。

**Blender のビューポートに表示**
- RefBoard で動画を右クリック ▸ **Blender ビューポートに表示 (Blender 뷰포트에 띄우기)**。3D カーソルの位置に、正面(Front ビューの方向)を向いたリファレンス画像(Empty)として追加されます。
- 通常のオブジェクトと同じように移動・回転・拡大縮小できます。サイドバー(`N`) ▸ **RefBoard** タブで大きさ・不透明度を変えたり削除したりします。
- どのコマを表示するかを毎フレーム RefBoard と同じ方法で計算します。fps が違っても、再生速度を変えても、ループ区間があっても RefBoard と同じコマが表示されます。

**カメラ背景に送る**
- RefBoard で動画を右クリック ▸ **Blender のカメラ背景に送る (Blender 카메라 배경으로 보내기)**。アクティブカメラの背景動画(ムービークリップ)として追加され、カメラ視点(`Numpad 0`)で表示されます。
- NAS の動画は一度ダウンロードして `%APPDATA%\refboard\blender-clips` に置きます。

## ソースから実行 · ビルド

[Node.js](https://nodejs.org/) 20 以降が必要です。

```bash
npm install
```

```bash
npm start
```

- ソースから実行している間にコードが変わると、画面上部に **新しいバージョンのお知らせ** が表示されます(インストール版ではオフ)。
- Blender アドオンの設定の **ソースフォルダ(開発用)** にこのフォルダを指定すると、アドオンの **RefBoard を開く** がソースから実行します。

リリースファイルの作成(`dist/` に作られます):

```bash
npm run dist
```

```bash
npm run addon
```

自動テスト(テスト用の WebDAV またはフォルダが必要):

```bash
npm run selftest
```

環境変数 `RB_TEST_URL` / `RB_TEST_USER` / `RB_TEST_PASS`(WebDAV)、または `RB_TEST_TYPE=local` と `RB_TEST_URL=<フォルダ>` でテスト用のソースを指定します。

ロゴを変えるには、`assets/logo-source.png`(白地に黒のロゴ)を差し替えて `python scripts/make-icons.py` を実行します。
